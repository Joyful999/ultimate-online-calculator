Formula

Result = Number^(1 ÷ Root)

Worked Examples

Square root of 144 = 144^(1/2) = 12.

Cube root of 27 = 27^(1/3) = 3.

How to Use the Square Root Calculator

  1. Enter the number you want a root of.
  2. Leave the root at 2 for a square root, or change it (e.g. 3 for a cube root).
  3. Press Calculate to see the result, with a check calculation shown.
